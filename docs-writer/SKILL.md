# Gemini CLI documentation

Read that checkout's current contribution and documentation conventions. Use its
actual filenames, sidebar structure, and formatter only when they exist. Preserve
the user's requested tone and scope. Check facts against current code and verify
links. Run the repository's applicable formatter directly when authorized; do not
invent a separate approval step or apply Gemini conventions to other repositories.

# Manifests

Inspect the live schema and installed resolver before changing membership.
Global selection lives in `~/.agents/skills.json`; project selection lives in
`<repo>/.agents/skills.json`. This host selects the `min-global` set globally.

Sets select canonical names. Project inheritance composes a map, not copied
bytes. Keep one unambiguous target per name; inspect `explain`, `status`, or sync
preview supported by the installed CLI to establish the resulting target and
precedence. Do not reproduce a historical pruning algorithm in this skill.

Remove defaults in the owning set, not by deleting a generated symlink. An
optional capability can remain in the catalog and a project-specific set.

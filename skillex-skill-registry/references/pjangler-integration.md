# PJangler integration

PJangler owns new-project bootstrap and exact template migrations. Skillex owns
catalog bytes, reference-only compositions, and skill activation. Hook dialect
rendering belongs to agent-config-fanout; index parity to gitignore-maintenance.

Inspect the installed PJangler help and the repository's current CommonProject
template before migrating. Preview the specific change. Do not assume an old
published CLI is broken, hard-code a local build alias, or copy obsolete
`provision-packs.py` payload workflows into a current project.

After applying, check the project's manifest, scope root, client aliases, and
actual selected skills. Treat generated file drift at its template source.

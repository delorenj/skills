# antislop-ui

Review visual hierarchy and interface composition against the user's brief and existing product identity.
Use [shared criteria](../antislop/SKILL.md) for factual truth, scope, and quality.

Read only the relevant section of [patterns](references/patterns.md) when you
need examples or a specific failure mode. Do not apply the whole catalog to
every edit. A familiar pattern is not a defect without a concrete consequence.

Preserve deliberate voice, typography, palette, and motion choices. For a new
UI direction, use `impeccable`; this skill critiques execution of that direction.
Verify the affected text or interface and explain material changes briefly.

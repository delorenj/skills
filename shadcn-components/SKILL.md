# shadcn components

Inspect the target repository's component setup and nearby code before adding
files. Reuse its registry, import aliases, styles, accessibility patterns, and
package manager. Confirm the intended package and destination from components.json
and existing components. Install only dependencies required for the requested UI.

Implement the requested behavior and verify interaction, focus, states, and
responsive layout using the repository's checks. Existing identity and the user
brief control design choices. Use [component examples](references/component-examples.md)
only for a relevant pattern; their paths are illustrative.

# Optional design direction worksheet

Use only when the user explicitly selects a new visual direction. For an
existing product, first record its current identity and requested changes.

- Responsive behavior and representative content/viewports:
- Motion purpose and reduced-motion behavior:
- Assets available, placeholders, and missing decisions:

No font, color, layout, or punctuation is universally banned. Motion is optional;
continuous decorative animation is not a required component state. Use impeccable
for design decisions, design-md for faithful extraction, and the Antislop shared
criteria for the requested review. Do not redesign merely to fill this worksheet.
